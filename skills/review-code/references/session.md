# Review session

Load only in session mode, after step 5 has produced the immutable review record. One-shot callers do not load this reference.

Present the complete would-be review: summary, findings, and questions, retaining the script-rendered commit-pinned links. Then list every routed item as a question the user can answer:

- For each ambiguity, give both supported readings and the one applied, and ask which reading should govern.
- For each unrecoverable input, name the missing input, what it gates, and who can supply it; ask for that input.
- For each open material question, including an unanswered required issue, state how the answer settles the recorded decision and who can answer it.

In a headless session, each ask becomes a line in the report. End with an exit summary of what was asked, any answers supplied, and what remains open; answers stay beside the record.

The conversation rules for decisions, evidence-based amendments, and extra verifier batches arrive with the session-mode issue (#233). Until then the session does not amend the record or authorize extra batches.
