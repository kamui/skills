## Run date, model, harness

- **Run date:** 2026-09-03.
- **Model: `claude-sonnet-5` on the orchestrator and all three sub-agents.** Passed **explicitly** on
  every `Agent` call and **verified afterwards** by reading `message.model` from every assistant turn

## What this run also shows

- **The third drift was missed, and the run says so plainly.** `validate-completion.py:2949` still
  hardcodes the retired Volatile-term regex. It appears nowhere in either finder's output. The
  orchestrator goes further than required: it notes that the Requirements finder's own reported
  old-fragment search string should in principle have matched that line, and that its reported hit
  list does not include it — leaving open whether this is a genuine recall miss or a search-tooling
  artifact, rather than guessing.
- **C3 came back partial, self-reported.** The Code finder returned a 20-row ledger with 15 explicit
  acquittals; the Requirements finder did not return a ledger in the brief's required shape, keeping
  its acquittal reasoning inline in prose instead. The orchestrator flagged this as a partial miss
  for that axis and declined to fabricate rows. Worth watching: the Requirements axis's search
  process is less auditable from its output than the Code axis's.
- **Calibration moved and was defended.** The verifier independently confirmed `must-fix` on
  `shortlist-narrow/SKILL.md:46`, reasoning that the file is cited elsewhere as "the implemented
  contract" for the Narrow stage and is followed as an executed step, and that this PR's own fixture
  supplies an instance the fixed list cannot cover. The orchestrator reported the resulting
  `Changes Requested` as measured rather than reshaping it toward the `Approved (advisory)` the C1
  checklist anticipated.

## Process disclosure

A paused orchestrator does not receive its own sub-agents' completion notices, so the session relayed
them and pointed at the saved report files. In every case the finders and the verifier had already
returned before any relay was sent, so no relay could have shaped review findings — only which
disclosures the final report makes. The session did ask for specific things to be stated plainly
(whether each of the three known items appeared, and in which bucket). Recorded here so the record
shows it. No finder or verifier received any information about a prior run or an expected outcome;
each got only the phase-1 packet, the pinned material, and its own brief.
