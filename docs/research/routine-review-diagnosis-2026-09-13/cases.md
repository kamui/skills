## Case decisions

The following cases investigate apparent additions or widened remedies after a selected publication. Published findings listed in the run table are recoveries, not misses. Material means an established consequential correctness or decision failure; a low-impact reporting omission remains recorded without becoming discovery-study evidence. ### C01 — omitted duplicate-concept counts

**Supported low-impact historical omission in R17, not demonstrated material discovery loss.** [Issue #153](https://github.com/kamui/skills/issues/153) required counts per attempt. At R17's head `5379447d0fd99819144955214cbe6d64be1df61d`, `scripts/decide.py`'s comparison output lacked the field; that output remained absent at R16's `9065103792b25628e8b6fe1b890a015508e5d5e5`. R17 published the distinct packet-integrity defect, but no duplicate-count finding. R16 then [published the omission as P3 must-fix](https://github.com/kamui/skills/pull/201#discussion_r3994642106): readers could not distinguish an established zero from missing measurement. This was legitimate acceptance scope, available from the issue and authored comparison code at the first head. The [addressing record](https://github.com/kamui/skills/pull/201#issuecomment-5642756201) identifies `5626600` / `21da1a5` as the repair, [adding explicit counts and distinguishing item/concept multiplicity](https://github.com/kamui/skills/commit/562660016c1d62719d6a9fe82de8e6267e0368c9); the grids and scorecards remained unchanged. No changed study decision or material defect-recovery consequence is established. Its mandatory acceptance status makes it a real omission; treating that status alone as material would conflate obligation with demonstrated consequence. If a broader materiality definition includes mandatory reporting gaps, C01 adds one historical concept/run, with the same unknown-stage and current-release limitations. One omission, one missed run (R17), one later detecting run (R16). **Loss stage unknown**: no private ledger proves whether R17 discovered, rejected, omitted, or verified it. Remedy is supported by the changed comparison schema and the existing addressing verification; no new grading was performed.

### C05 — a broad ruling-table glob includes superseded input

**One supported material historical miss across R19 and R18, both declaring v5b-12.** This is distinct from C02: choosing the right derived file does not restrict which ruling tables the command reads. At R19 head `34d6bbd38e9365d850dc297ab99767ea7ba739f2`, the [recipe](https://github.com/kamui/skills/blob/34d6bbd38e9365d850dc297ab99767ea7ba739f2/docs/research/bounded-discovery-grading-2026-09-11/README.md#L291-L302) uses `rulings-target-*.json` for freeze/publish while its public artifact description retains a pre-resume table beside the final tables. That shell pattern admits the superseded file as well as the two intended final tables. The same broad pattern remains, and also reaches amended derivation, at R18's [head](https://github.com/kamui/skills/blob/96f3715aca54e0dec38e5efa05d7918ccd2ca2a0/docs/research/bounded-discovery-grading-2026-09-11/README.md#L351-L363). The helper iterates every supplied ruling file, so the recipe can freeze the wrong input set and double the target's cue inputs. This breaks the claimed reproducibility of the grading summary, a material obligation of the newly added tooling; the commands and retained-file description were available in the legitimate review scope.

Neither R19's five published findings nor R18's old-derived-file finding names this extra-input failure. The [correction record](https://github.com/kamui/skills/pull/200#issuecomment-5631281940) explicitly distinguishes the second defect and reports reproduction and correction in bash and zsh. [Commit `cf044bc`](https://github.com/kamui/skills/commit/cf044bc9cb6c74c6407bcb5ddd6d5dcb1930095b) narrows all table arguments to `rulings-target-[AB].json` and adds an output comparison. The head commands, standard glob membership, helper input handling, and already-retained reproduction support the defect; the patch alone is not the evidence. No sealed table contents were opened, so this diagnosis does not independently recompute the numerical grading results or claim a changed adoption decision.

**Earliest loss stage unknown for both runs.** A later correction cannot reveal whether the earlier primary never discovered this, rejected it, failed to route it, received a verifier refutation, or lost it before publication. R18's public account of an independent disposition check exposing C02 does not establish what happened to C05. The existing correction supplies a concrete remedy under [#152](https://github.com/kamui/skills/issues/152); no new policy repair is justified from this trace gap. Two missed publications on one target/defect are **one distinct concept**, not recurring independent discovery misses.
