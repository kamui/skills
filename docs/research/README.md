# Research archives

The token `snapshot-path-omitted` redacts paths, skill names, and branch names of the deleted reviewer skill and its numbered prototype snapshots in historical records. It is not a literal path. Recorded results and measurements are unchanged; archived commands that require that snapshot cannot be replayed from this repository.

The rerunnable review-code benchmark and its tools now live in [`kamui/code-review-bench`](https://github.com/kamui/code-review-bench). Historical commands that use `bench/` or its forwarding scripts under `docs/research/tools/` must run from that repository. The removed interface-metrics collector remains available in this repository's Git history.
